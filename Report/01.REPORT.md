## 2. 핵심 결정·산출물

### 2.1 도메인·API

| Rule | 내용 |
|------|------|
| R1 | `X'-Y"` → X + Y/12 (`3'-6"` = 3.75, 3.5 아님) |
| R2 | meter 기준 feet↔yard 비율 고정, 혼동 시 `fail` |
| R3 | 견적용 출력 자릿수 (선택) |
| R4 | `단위:값` / 건축 표기 / 그리드 검증 |

API: `validate_lines(grid) -> {"status": "pass"|"fail"|"incomplete", "failed_lines": [...]}`
