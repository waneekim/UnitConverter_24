## 4. 핵심 구현

### 4.1 API (PRD §5.2)

```python
convert_length(spec, estimate_places=2) -> ConversionResult
convert_lengths(specs, estimate_places=2) -> list[ConversionResult]
```

`ConversionResult`: `input_spec`, `feet_decimal`, `meter`, `feet`, `yard`, `estimate_rounded`

### 4.2 설정 SSOT

`config/conversion.json` — `feet_per_meter`, `yard_per_meter`, `r1_arch_inch_divisor`, `estimate_decimal_places`, `known_units`. 파일 없을 시 `constants._DEFAULTS` fallback.

### 4.3 Boundary 출력 형식

```text
meter:2.5 = 2.5 meter
meter:2.5 = 8.2021 feet
meter:2.5 = 2.734 yard
```
