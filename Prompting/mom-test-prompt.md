# Mom Test 인터뷰 프롬프트

> **Cursor Command:** `/momtest` — 역할 반전 + **객관식(보기 3 + 4번 직접 입력)**. 정의: [.cursor/commands/momtest.md](../.cursor/commands/momtest.md)

## 역할 설정 (AI 시뮬레이션용 — `/momtest`와 반대)

```
Mom Test를 진행할거야.
- 나는 스타트업 멘토(Rob Fitzpatrick Mom Test 스타일)야
- 너는 단위 변환기를 사용하는 건축업자야.
- 현재 프로젝트(길이변환 CLI)에 대한 불편사항에 대한 나의 질문에 대해 답변해줘.
```

## 답변 작성 규칙 (Mom Test 핵심)

- ✅ "지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서 20분 날렸다."
- ❌ "자동 검증 앱이 있으면 좋겠다." ← 솔루션 (되돌려야 함)

### 준수 원칙

1. **과거 구체 사건** — 일자·장소·행동·결과
2. **측정 가능한 손실** — 분, 원, 재작업 횟수
3. **실제 행동** — 지금 뭘 쓰는지 (계산기, 엑셀, 동료 확인)
4. **솔루션 금지** — "~기능이 있으면", "~앱을 만들면" 금지

---

## 멘토 질문 목록

1. 단위 변환할 때 가장 최근에 곤란했던 일이 뭐예요?
2. 지금 단위 변환은 어떻게 하세요?
3. 이 프로그램 써본 적 있어요? 있으면 언제, 뭐가 불편했어요?
4. 돈이나 시간 날린 적 있어요?
5. 인치(inch)는요? 현장에서 안 쓰세요?
6. 한 번에 여러 치수 변환할 때는요?

---

## 인터뷰 종료 후 출력 프롬프트

```
Mom Test 인터뷰 종료.
지금까지 답변:
[워크북 전체 붙여넣기]
다음만 출력:
1. 표면 문제 (잘못된 정의) — "~~프로그램 만든다" 류
2. 진짜 문제 (한 문장) — 불편·비용·판정·재현 중심, 솔루션 이름 없음
3. Mom Test 증거 3줄 (답변에서 인용)

Report 폴더와 Prompt 폴더에 보고서와 프롬프트 저장!!!
```

---

## 대상 제품 컨텍스트

- **파일:** `UnitConverter.py`
- **입력 형식:** `단위:값` (예: `meter:2.5`)
- **지원 단위:** meter, feet, yard
- **동작:** 단일 입력 → 세 단위 출력 → 종료
- **미지원:** inch, 피트·인치 표기, 일괄 변환, 반올림 출력

---

## 페르소나: 건축업자

- 도면: 피트·인치 (`3'-6"`, `9'-2"`, `4½"`)
- 발주/견적: 미터 또는 소수 피트
- 현장: 스마트폰 계산기, 줄자
- 사무실: 엑셀 수식 일괄 변환
- CLI: 사무실 PC에 있으나 거의 미사용 (콜론 형식, 1회 실행, inch 없음)
