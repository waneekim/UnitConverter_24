# Mom Test — 사용자 인터뷰 (Rob Fitzpatrick · 객관식)

`/momtest` 실행 시 **즉시 Mom Test 인터뷰**를 시작한다.  
근거: [Prompting/mom-test-prompt.md](../../Prompting/mom-test-prompt.md) — **역할 반전** + **객관식 3+1**.

## Phase 선언 (필수)

응답 **첫 줄**:

```
Phase: MOM_TEST
```

## 역할 (반전)

| 역할 | 담당 |
|------|------|
| **멘토** | **Cursor (AI)** — 질문·코칭·정리 |
| **건축업자** | **사용자** — 번호 선택 또는 4번 직접 입력 |

- AI가 건축업자로 **대답하지 않음**.

---

## 객관식 형식 (필수)

매 질문마다 **아래 구조**로 제시한다.

```markdown
**Q{n}.** {질문 문장}

1) {보기 — 과거 구체 사건·행동·손실 예시}
2) {보기 — 과거 구체 사건·행동·손실 예시}
3) {보기 — 과거 구체 사건·행동·손실 예시}
4) 직접 입력 — **언제·어떤 치수·몇 분/원**을 적어 주세요.

→ `1`~`3` 번호만 보내거나, `4: (본인 경험)` 형식으로 답하세요.
```

### 보기 작성 규칙

| 규칙 | 내용 |
|------|------|
| 보기 1~3 | **솔루션 제안 금지** — "~앱이 있으면" ❌ |
| 보기 1~3 | 과거 행동·측정 가능 손실(분·원) **예시** — Mom Test 스타일 |
| 4번 | 항상 **직접 입력** — 사용자 본인 사건 |
| 한 턴 | **질문 1개**만 |

### 응답 처리

| 사용자 입력 | 멘토 동작 |
|-------------|-----------|
| `1` / `2` / `3` | 해당 보기 **요약 인용** 기록 후 다음 Q (너무 짧으면 4번처럼 구체화 1문장 요청) |
| `4: ...` 또는 자유 서술 | 원문 기록 → 다음 Q |
| 솔루션만 말함 | 코칭 후 **같은 Q** 재제시 |
| `종료` / `끝` | 정리·저장 |

## 인터랙션 (마크다운 vs 선택 UI)

| 방식 | 마우스·키보드 선택 | 직접 입력 box |
|------|-------------------|---------------|
| **채팅 마크다운** (`1) 2) 3)`) | ❌ 텍스트만 — 번호 타이핑 필요 |
| **AskQuestion 도구** | ✅ 보기 **클릭** 선택 (Cursor 제공) | ✅ **Other** 옵션으로 자유 입력 |
| **Canvas** (React 폼) | ✅ 라디오·버튼 | ✅ `<input>` 가능 — 별도 `/canvas` 작업 |

### 권장 (`/momtest` 실행 시)

1. 질문 본문은 마크다운으로 표시 (맥락·코칭)
2. **즉시 `AskQuestion` 호출** — 보기 1~3 + **4번 = Other(직접 입력)**
3. 사용자가 Other 선택 시 채팅에 이어서 구체 사건 입력

`AskQuestion` 예시 구조:

- `prompt`: Q{n} 질문 문장
- `options`: id `1`/`2`/`3` — SSOT 보기 텍스트
- 사용자가 **Other** 선택 가능 → 4번 직접 입력에 해당

**금지:** 마크다운만으로 "클릭 가능한 버튼"이 된다고 안내하지 않음.

## 질문·보기 SSOT (6문)

### Q1. 가장 최근에 곤란했던 일

1) cm/mm를 inch로 바꾸지 못해 **10분** 허비했다  
2) `meter: 2.5` 형식을 몰라 cmd에서 **여러 번** 시도했다  
3) `3'-6"`을 3.5피트로 잘못 넣어 발주서를 고쳤다 (**15분**)  
4) 직접 입력

### Q2. 지금 단위 변환 방법

1) **핸드폰** 단위 변환기 — 치수당 **1분**  
2) **엑셀** 수식으로 사무실에서 일괄 변환  
3) 현장 **계산기** + 종이 메모 (장갑 벗고 입력)  
4) 직접 입력

### Q3. `UnitConverter.py` 사용 경험

1) **방금** 테스트 — 단건 입력은 됐지만 **바로 포기**  
2) **한 달 전** 1회 — 콜론 형식이 익숙하지 않아 안 씀  
3) **사용 안 함** — cmd/search black screen 부담  
4) 직접 입력

### Q4. 돈·시간 손실

1) 형식 오류·재시도 — **5~10분**  
2) 인치 치수 **하루 10회+**, 회당 **1분+** 집중 단절  
3) 야드/피트 착각 **재주문·배송비 3만 원** (과거)  
4) 직접 입력

### Q5. 인치(inch) 사용

1) **매일** — `3'-6"`, `4½"` 도면 표기  
2) 문턱·단차만 **분수 인치** (`4½"`) 자주  
3) inch는 쓰지만 **현장에선 핸드폰** — PC/cmd는 안 씀  
4) 직접 입력

### Q6. 여러 치수 한꺼번에

1) 핸드폰에 **순차 입력** — 지우고 다시 입력 반복  
2) **엑셀** 한 열에 넣고 수식 복사 (**8분** / 8개)  
3) `UnitConverter.py --batch`는 **모름** — cmd 8번 열기 부담  
4) 직접 입력

**추가 Q (갭 보일 때만):** cmd 망설임, 견적서 반올림 수동 작업 등 — 동일 3+1 형식.
